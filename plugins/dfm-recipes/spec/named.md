# The other formats (spec 1, named only)

Each is written in full when the first skill that needs it is built.

| Format | Holds | First needed by |
|---|---|---|
| counts | a source, a week, a fact, a group if any and a number (on a running week, the count to a day); what every counting skill gives the ledger | the weekly run |
| people | an id, the groups a person is in, their states and when each changed, where they came from, what they agreed to receive and on which channel; never a name or contact | follow ups |
| media | a recording or clip, its parts, its copies per channel and their sizes | recording to clips |
| inbox | messages in: from (an id), channel, date, kind and text | replies to a plan |
| forecast kept | each forecast with its date and inputs, kept so later weeks can check it ([how a forecast is worked out](forecast.md)) | what ifs |
| run log | every write: what, where, before and after, by which skill | every writing skill |
